# Bridal Braid Mirror

Project: StyleMirror AI

Build a premium, responsive AI Personal Hair Stylist website called StyleMirror AI.

Product vision

StyleMirror AI helps users visualize hairstyles before trying them in real life. Users can upload their face photograph, outfit photograph or haircut reference and receive personalized hairstyle recommendations and visual previews.

Target audience

Launch with Indian bridal and occasion styling, but design the product to support men and women and everyday haircut styling in the future.

Brand identity

Premium beauty-tech aesthetic.

Warm ivory, blush pink, muted rose and mocha colour palette.

Elegant serif headings and clean sans-serif body text.

Large editorial hairstyle photographs.

Minimal, luxurious and modern interface.

Responsive desktop and mobile design.

Main features

1. Occasion Stylist

Create a guided multi-step workflow:

Upload face photograph.

Upload outfit photograph.

Select occasion.

Select hairstyle preferences.

Select accessory preferences.

Enter custom instructions.

View hairstyle recommendations.

View hairstyle previews.

Accessorize selected hairstyles.

Compare and save final looks.

Occasions must support multiple selections:
Wedding, Engagement, Reception, Mehendi, Haldi, Sangeet, Cocktail Party, Birthday, Festival, Casual Outing, Photoshoot, Graduation, Professional Event and Other.

When Other is selected, show a custom text field.

2. Hairstyle preferences

Include:

Aesthetic: Traditional, Modern, Elegant, Minimal, Romantic, Glamorous, Other.

Arrangement: Open, Half-up, Bun, Braid, Ponytail, Updo, Other.

Length: Short, Medium, Long, Keep Current, Other.

Texture: Straight, Wavy, Curly, Natural Texture, Other.

Support multiple selections where appropriate. Every Other option must reveal a custom input field.

3. Accessory Studio

Include:

Floral accessories.

Traditional jewellery.

Kundan and pearl pins.

Modern clips.

Minimal accessories.

Other.

Allow users to:

Upload accessory reference images.

Select accessory placement.

Choose subtle, moderate or heavy styling.

Request AI accessory recommendations.

Choose no accessories.

Experiment with multiple combinations.

4. Haircut Studio

Allow users to upload their photograph and a haircut reference or select a haircut name. Provide hairstyle previews and alternative haircut recommendations.

5. AI Stylist

Create a conversational styling assistant that considers uploaded photographs, outfit, occasion, hairstyle preferences, accessories and custom instructions.

6. Results

Display hairstyle recommendation cards, visual previews, alternative suggestions, accessory combinations, before-and-after comparison and save functionality.

Prototype requirements

This is initially a clickable prototype, not a production AI application.

Make every navigation item functional.

Connect all steps using Back and Continue.

Add conditional Other text inputs.

Support multi-select controls.

Support image upload previews.

Add loading and analysis states.

Use prepared sample images and simulated AI results.

Make accessory changes and hairstyle comparisons interactive.

Provide sample data so users can explore without uploading personal photos.

Do not connect paid APIs, payment gateways or production authentication yet.

Build a polished, cohesive product experience rather than a generic dashboard. Keep the architecture modular so actual image-generation AI and backend functionality can be integrated later.
